Tools

Software and agent skills, each doing one job.

  • ATProto-links-bot — Relays paper links shared in the CoLab Discord to Bluesky and Semble, via a scheduled GitHub Action.
  • claude-readable-reports — Claude Code output styles: one that makes an agent's final report readable, one for co-writing papers and grants.
  • grant_search — Agentic skill for finding AI research grants and funding calls.
  • paper-geo — Make your papers and code findable, and correctly described, by AI answer engines and scholarly indexes.
  • paper-sharpener — Agentic Claude Code skills for academic writing: review simulation, revision, and prose improvement.
  • social-follow — Follows research collaborators across Bluesky, Twitter/X and LinkedIn from a CSV, with a human review step and no scraping.
  • Xthread2social — Republish an X/Twitter thread to your own Bluesky and Mastodon accounts. No API keys, no server, no paid tier.
